# ICS 课表与周末安排导入

关联 https://github.com/thu-info-community/thu-info-app/issues/932 。首版实现 Android/iOS 的 ICS 导入；CSV/Excel、HarmonyOS 文件选择暂不支持。

## 使用

在课表的设置弹窗，或“设置 → 课程表”中选择“从 ICS 导入”。先核对日期范围，再选文件、检查预览、确认导入。默认范围来自当前显示的学期；可以调整为小学期或某个周末，最多 366 天。日期范围不会改变全局学期设置。

- **补充导入**：适合周末个人安排。已有课程不变，完全重复的名称、地点、开始和结束时间会跳过，时间冲突只提示。
- **覆盖日期范围**：适合实际安排与官方公布课表不同的小学期。移除所有开始时间落在范围内的既有安排，再添加勾选的新日程。即使某天没有新日程，该天的旧安排也会移除。范围外的数据不变。

覆盖前会显示受影响记录并再次确认。**先使用原有“导出日历”备份；被覆盖的本地安排不能自动恢复。** 官方日程在覆盖范围内持续屏蔽，重启或刷新都不会恢复旧课表。导入页面显示这些范围；“恢复官方日程”在联网刷新成功后解除所有覆盖范围，保留导入的本地日程（完全重复项按原有刷新规则合并）。该操作不能找回已覆盖的本地安排。

所有导入项是本地自定义日程，可按原有方式编辑或删除。若导入后没有显示，请检查当前学期/周、本地日程开关及隐藏周末设置。只做文件导入，不向学校保存日程，不建立订阅；后续修改原文件不会自动同步。

## 在电脑准备文件

可以使用支持导出 ICS 的日历工具安排好时间，再将导出的 `.ics` 文件传到手机。“文件”应用中的云端文件需要先下载。文件只在本地解析，复制到应用缓存的文件读取后即清理。

`test/fixtures/weekend-plan.ics` 是不含个人数据的示例：2026-09-05 起每周六 09:15–09:50 阅读，2026-09-06 起每周日 16:30–17:20 运动，各重复四次。导入示例时将范围设为 2026-09-01 至 2026-09-30。时间不需要对齐学校节次。

## 支持范围

- UTF-8 ICS、中文、折行、转义、普通定时事件，按天/周重复（包括隔周）、COUNT/UNTIL、RDATE/EXDATE 和单次改期。
- UTC 和文件内 VTIMEZONE；无时区事件按设备本地时区处理并提醒。未知 TZID 不猜测时间。
- 全天、跨午夜、其他重复规则、范围改期、无效事件明确提示。异常重复系列整体跳过，避免只导入部分错误安排。取消的事件不导入；不处理附件、提醒、与会者或远程 URL。
- 最多 5 MiB、1,000 个 VEVENT、5,000 个展开时间片、50,000 次迭代；超限整次失败，不静默截断。展开范围最长 366 天。
- THUInfo 自身导出文件按其 PRODID 识别，还原导出时附加的自定义/考试前缀；其他来源名称原样保留。独立事件不会仅因旧导出 UID 相同而丢失。

## 实现与验证

解析模块不读写 Redux，也不依赖学校会话。文件读取、解析预览、课表写入分别实现。批量 action 在变更前验证整批记录，并基于提交时的状态去重。

新增可选 `replacementRanges`，以绝对时间保存覆盖范围，并随原有课表同步传输。旧存档没有此字段时按空范围处理。持久化版本升至 7：逐个时间片判断旧格式，修复第一门官方课被覆盖为空后误触发迁移的问题，并让旧的六位数字前缀清理只执行一次，避免破坏新日程名称。

自动化验证命令：

```sh
yarn workspace @thu-info/app test --runInBand
yarn workspace @thu-info/app lint
```

测试覆盖解析、异常限制、真实导出函数往返、文件复制/清理、日期选择、勾选、确认覆盖、恢复失败、去重、刷新和持久化迁移。

2026-08-31 本地验证结果（Windows）：

- Jest 全量测试：41 通过，1 个原有测试跳过；使用 `--detectOpenHandles` 复测正常退出。
- App ESLint：0 错误，3 个原有警告。
- TypeScript：与基线提交 `8d6f0df8` 对比，均为 38 条已有诊断，没有新增诊断；不能表述为项目类型检查全量通过。

- iOS 原生编译、`pod install` 和文件选择实机验证尚未执行；需要 macOS/Xcode 更新并核验 `Podfile.lock`。HarmonyOS 原生构建和跨设备课表同步也未验证。

平台验收仍须分别进行：

1. Android 从下载目录及 content URI 选文件；iOS 从“文件”和 iCloud 选文件。
2. 导入示例，核对周末精确时间；取消选择或确认时数据不变。
3. 覆盖测试范围，核对影响清单；重启并刷新，确认官方旧安排仍屏蔽，范围外日程保留。
4. 网络失败时恢复操作保留覆盖设置；恢复成功后官方日程重新显示。
5. HarmonyOS 入口隐藏，平台适配文件不得加载 Android/iOS 的文件选择原生模块。

没有真机/模拟器执行记录时，不能把单元测试或 Metro 打包通过表述成平台验收完成。
